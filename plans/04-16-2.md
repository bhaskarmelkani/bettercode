# Message Panel UI Restructuring — Implementation Plan

## Overview

Four milestones to restructure the main session content panel:
1. **M1** — Fix duplicate diffs (quick correctness fix)
2. **M2** — Group consecutive tool calls into an accordion (biggest visual improvement)
3. **M3** — Visual hierarchy polish (prominence, spacing, separators)
4. **M4** — Smarter focus mode (ctrl+o shows summary instead of hiding tools)

After each milestone: `cd packages/tui-ink && bun typecheck && bun test test/` must pass.

## M1: Fix Duplicate Diffs

**Problem:** `loadMessageDiff` in `store.ts:728-748` passes `parentID` (the user message) as the "from" snapshot for every assistant message in a turn. Since all assistant messages in a turn share the same `parentID`, the server returns the same cumulative diff for every one of them, causing identical diff blocks to appear multiple times.

**Fix:** Only load diffs for the **last completed** assistant message in each conversation turn. A "turn" ends at the next user message.

```tsx
  // A turn = sequence of assistant messages following a user message.
  // We only want the final one (closest to the next user msg or end).
  const lastInTurn = new Set<string>()
  for (let i = 0; i < messages.length; i++) {
```

**Goal:** Group consecutive tool calls of the same kind into a single collapsible row. Single-tool sequences still render as individual `ToolPart`.

```ts
import type { Theme } from "../theme"

export function toolKind(tool: string, theme: Theme) {
  const t = tool.toLowerCase()
  if (t.includes("read") || t.includes("glob") || t.includes("grep") || t.includes("search"))
    return { icon: "◇", color: theme.cyan, label: "read" } as const
  if (t.includes("write") || t.includes("edit") || t.includes("patch"))
    return { icon: "✎", color: theme.yellow, label: "write" } as const
  if (t.includes("bash") || t.includes("shell") || t.includes("execute"))
    return { icon: "$", color: theme.green, label: "exec" } as const
  return { icon: "⬡", color: theme.pink, label: "mcp" } as const
}

export function isWriteTool(tool: string) {
  const t = tool.toLowerCase()
  return t.includes("write") || t.includes("edit") || t.includes("patch")
}
```

### TODO 2b — New ToolGroup component

**New file: `packages/tui-ink/src/components/parts/ToolGroup.tsx`**

This renders a collapsed/expanded group of consecutive tool calls of the same kind.

```tsx
import React, { useState } from "react"
import { Box, Text } from "ink"
import type { ToolPart as ToolPartSDK } from "@opencode-ai/sdk/v2"
import { useTheme } from "../../theme-context"
import { toolKind } from "../../utils/toolKind"
import { isOpen } from "./ToolPart"

interface Props {
  parts: ToolPartSDK[]
  // When true: render as single non-expandable summary line (overview/focus mode)
  overview?: boolean
}

function dur(ms: number) {
  if (ms < 1000) return `${ms}ms`
  return `${(ms / 1000).toFixed(ms < 10_000 ? 1 : 0)}s`
}

export const ToolGroup = React.memo(function ToolGroup({ parts, overview }: Props) {
  const theme = useTheme()
  const [open, setOpen] = useState(false)

  const first = parts[0]
  const kid = toolKind(first.tool, theme)
  const n = parts.length

  // Aggregate status: error if any errored, running if any running, else completed
  const hasError = parts.some((p) => p.state.status === "error")
  const hasRunning = parts.some((p) => p.state.status === "running" || p.state.status === "pending")
  const aggStatus = hasError ? "error" : hasRunning ? "running" : "completed"

  const statIcon = aggStatus === "error" ? "✗" : aggStatus === "running" ? "◎" : "✓"
  const statColor = aggStatus === "error" ? theme.red : aggStatus === "running" ? theme.yellow : theme.green

  // Total duration
  let totalMs = 0
  for (const p of parts) {
    if ("time" in p.state) {
      const end = "end" in p.state.time ? p.state.time.end : Date.now()
      totalMs += end - p.state.time.start
    }
  }
  const totalTime = totalMs > 0 ? dur(totalMs) : ""

  // Unit label: "files" for read/write, "commands" for exec, "calls" for mcp
  const unit = kid.label === "read" ? "files" : kid.label === "write" ? "files" : kid.label === "exec" ? "commands" : "calls"
  const label = `${kid.label === "read" ? "Read" : kid.label === "write" ? "Edited" : kid.label === "exec" ? "Ran" : "MCP"} ${n} ${unit}`

  const chevron = overview ? " " : open ? "▾" : "▸"

  return (
    <Box paddingLeft={3} flexDirection="column" flexShrink={0}>
      {/* Group header row */}
      <Box
        flexDirection="row"
        justifyContent="space-between"
        onClick={overview ? undefined : () => setOpen((v) => !v)}
      >
        <Box flexDirection="row" gap={1} flexShrink={1}>
          <Text color={theme.overlay}>{chevron}</Text>
          <Text color={statColor}>{statIcon}</Text>
          <Text color={kid.color}>{kid.icon}</Text>
          <Text color={theme.subtext}>{label}</Text>
        </Box>
        <Text color={theme.overlay}>{totalTime}</Text>
      </Box>

      {/* Expanded: compact child rows (no further expand, just title + time) */}
      {!overview && open && (
        <Box paddingLeft={4} flexDirection="column">
          {parts.map((p) => {
            const s = p.state
            const childStat = s.status === "error" ? { icon: "✗", color: theme.red }
              : s.status === "running" ? { icon: "◎", color: theme.yellow }
              : s.status === "completed" ? { icon: "✓", color: theme.green }
              : { icon: "◌", color: theme.overlay }
            const childTime = "time" in s ? dur(("end" in s.time ? s.time.end : Date.now()) - s.time.start) : ""
            const title = ("title" in s && s.title) ? s.title : p.tool
            return (
              <Box key={p.id} flexDirection="row" justifyContent="space-between">
                <Box flexDirection="row" gap={1} flexShrink={1}>
                  <Text color={childStat.color}>{childStat.icon}</Text>
                  <Text color={kid.color}>{kid.icon}</Text>
                  <Text color={theme.overlay} wrap="truncate-end">{title}</Text>
                </Box>
                <Text color={theme.overlay}>{childTime}</Text>
              </Box>
            )
          })}
        </Box>
      )}
    </Box>
  )
})
```

### TODO 2c — Grouping logic in AssistantMessage

**`packages/tui-ink/src/components/AssistantMessage.tsx`**

Add a `groupParts()` function and update the parts rendering:

```tsx
// Add at top of file:
import { ToolGroup } from "./parts/ToolGroup"
import { toolKind } from "../utils/toolKind"

// Add this function before the AssistantMessage component:
type GroupedPart =
  | (Part & { type: Exclude<Part["type"], "tool"> })
  | { type: "tool-group"; parts: ToolPartSDK[] }
  | { type: "tool"; part: ToolPartSDK }  // single tool, no group

function groupParts(parts: Part[], theme: Theme): GroupedPart[] {
  const result: GroupedPart[] = []
  let i = 0
  while (i < parts.length) {
    const p = parts[i]
    if (p.type !== "tool") {
      result.push(p as GroupedPart)
      i++
      continue
    }
    // Only group completed tools of the same kind
    if (p.state.status !== "completed") {
      result.push({ type: "tool", part: p })
      i++
      continue
    }
    const k = toolKind(p.tool, theme).label
    const run: ToolPartSDK[] = [p]
    i++
    while (
      i < parts.length &&
      parts[i].type === "tool" &&
      (parts[i] as ToolPartSDK).state.status === "completed" &&
      toolKind((parts[i] as ToolPartSDK).tool, theme).label === k
    ) {
      run.push(parts[i] as ToolPartSDK)
      i++
    }
    if (run.length === 1) {
      result.push({ type: "tool", part: run[0] })
    } else {
      result.push({ type: "tool-group", parts: run })
    }
  }
  return result
}
```

### TODO 2d — Height estimation updates

**`packages/tui-ink/src/components/MessageList.tsx`** — update `toolHeight()` and `estimateHeight()`

Tool groups collapse to 1 line (same as a single collapsed tool). When expanded, they need `1 (header) + N (child rows)` lines. Since heights are cached by message ID and the cache key includes `parts.length`, existing cache invalidation covers this.

The key insight: a group of N completed same-kind tools renders as 1 line collapsed (same as individual collapsed tools), so the collapsed-height estimate is correct without changes. The cached height will be recomputed naturally when a user expands a group (via height cache version increment).

## M4: Smarter Focus Mode (ctrl+o)

**Problem:** Current `focusMode` hides all tool calls entirely and shows only the last text part. This is too aggressive — the user can't see any record of what the agent did.

**Goal:** Focus mode shows:
- Agent prose (first paragraph, truncated if long)
- A single compact summary line of all tool activity: `◇ 3 read · ✎ 2 edit · $ 1 bash — 14.2s`
- Hides reasoning and compaction (keep current behavior)
- Hides diffs (keep current behavior)

### TODO 4a — Tool activity summary line

**New component in `packages/tui-ink/src/components/AssistantMessage.tsx`** (or inline function):

```tsx
function ToolSummary({ parts, theme }: { parts: Part[]; theme: Theme }) {
  // Count completed tool parts by kind
  const counts: Record<string, number> = {}
  let totalMs = 0
  for (const p of parts) {
    if (p.type !== "tool") continue
    if (p.state.status !== "completed") continue
    const k = toolKind(p.tool, theme).label
    counts[k] = (counts[k] ?? 0) + 1
    if ("time" in p.state && "end" in p.state.time) {
      totalMs += p.state.time.end - p.state.time.start
    }
  }
  const icons: Record<string, string> = { read: "◇", write: "✎", exec: "$", mcp: "⬡" }
  const parts2 = Object.entries(counts)
    .map(([k, n]) => `${icons[k] ?? "?"} ${n} ${k}`)
    .join(" · ")
  if (!parts2) return null
  const time = totalMs > 0 ? ` — ${totalMs < 1000 ? `${totalMs}ms` : `${(totalMs / 1000).toFixed(1)}s`}` : ""
  return (
    <Box paddingLeft={3} marginTop={1}>
      <Text color={theme.overlay}>{parts2}{time}</Text>
    </Box>
  )
}
```

## Risk Notes

- **Height estimation** — `ToolGroup` collapsed = 1 line = same as individual collapsed `ToolPart`. No height change. Expanding a group adds N child rows; the height cache is invalidated automatically by version key change. Verify scroll doesn't jump on group expand.
- **`groupParts()` and streaming** — Running/pending tools are never grouped, so real-time streaming tool rows appear individually. As tools complete, the parts array changes and `groupParts()` re-runs. This is correct and safe.
- **`lastText` index** — Currently computed over `parts` (original array). Keep it computed from `parts`, not `grouped`, to avoid off-by-one issues.
- **Click handling in ToolGroup** — Ink's `onClick` on `Box` requires `<App>` with `patchConsole=false`. Verify click works in the TUI. If not, fall back to keyboard: add `onKeyDown` on the group row when focused, similar to how ToolPart toggles via store.
